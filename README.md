# Kali Security Monitor

A Bash-based Linux Security Audit and Monitoring Toolkit developed for Kali Linux.

## Features

- System Information
- Logged-in User Monitoring
- Network Information
- Listening Port Detection
- Disk Usage Monitoring
- Memory Usage Monitoring
- Process Monitoring
- Security Health Score
- Automated Security Report Generation

## Technologies Used

- Bash
- Kali Linux
- Linux command-line utilities

## Commands Used

- hostnamectl
- who
- ip
- ss
- df
- free
- ps
- systemctl
- awk
- sed

## Security Score

The tool performs basic system health checks and calculates a security score out of 100.

The checks include:

- SSH service status
- Firewall status
- Disk usage
- Memory usage
- Running processes
